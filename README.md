# 音浪 YinLang

iPhone / iPad 通用版本位于 [`ios/`](ios/README.md)。GitHub Actions 会构建未签名 IPA，并验证 iPhone 与 iPad 模拟器。

独立安卓应用与可选 Docker 下载服务。安卓端直接运行五个平台的音乐目录适配和用户导入的 LX 音源。Navidrome 提供个人曲库。有声书支持导入随身听书 ZIP 插件。

## 安装与使用

安卓最低版本为 Android 11。安装包位于 `build/android/YinLang-0.8.0.apk`。

首页右上角使用无文字、无底框的 iOS 风格齿轮进入设置。「总设置 → 关于」显示应用实际版本号，可打开 [GitHub 主页](https://github.com/tbslantian)。

首页默认使用浅色杂志风，音乐和有声书用整图横幅作为入口。「总设置 → 首页与页面外观」可选择深色播放风或按时间切换。自动模式默认每天 07:00 切浅色、19:00 切深色，时间可修改。在线歌单和排行榜随外观调整，Android 12 及以上在卡片边缘和角标内取样封面进行局部模糊，Android 11 使用半透明边缘高光。已下载的歌曲可在「本机下载」点垃圾桶删除。

「发现音乐」用各栏目中的封面作为入口卡片背景。在线排行榜入口使用榜内歌曲的专辑封面，在线歌单入口使用歌单封面。刷新后，有多张可用封面时会轮换。

音乐库采用唱片主卡布局：左侧加宽的「发现」进入资料库推荐，右侧集中排列「歌曲、专辑、我喜欢的」。「最近添加」保留在发现页，艺术家可从歌曲的查看菜单进入。收藏入口保留一键播放。右上角使用较小的 Navidrome 官方图标进入连接与音质设置。

Navidrome 歌曲的「⋯ → 查看」提供关联专辑、关联艺术家和歌曲详情，播放器菜单也有相同入口。多人合作歌曲按服务器返回的艺术家编号分别列出，不拆分艺术家名称。歌曲详情分为基础信息、扩展信息和回放增益，可查看歌词、音轨及碟号、格式、时长、码率、采样率、位深、声道、播放次数和时间、文件路径与大小。优先显示列表已有信息，并通过 [getSong](https://opensubsonic.github.io/docs/endpoints/getsong/) 获取当前账号可见的完整数据；缺失字段显示「无数据」。详情中的专辑和艺术家可继续进入对应页面。

Navidrome「发现」分为随心听、常听专辑、随机推荐和最近添加。随心听提供歌曲封面、音质、时长、服务器收藏及更多操作，也可播放全部；常听专辑展示当前账号的专辑播放记录；随机推荐和最近添加使用可横向滑动的专辑封面。每栏可独立刷新或查看全部，随机栏目可换一批，常听及最近添加可继续加载更多专辑。「个性化 → 推荐类型」控制歌曲或专辑优先。推荐列表按服务器及账号缓存，普通返回复用缓存，封面进入可见区域后才请求缩略图，横向滑动后继续加载新出现的封面。接口依据 [OpenSubsonic 专辑列表](https://opensubsonic.github.io/docs/endpoints/getalbumlist2/)。

1. 进入「音乐 → 音乐设置」导入支持相应平台的 LX JavaScript 音源。在线歌单可以用关键词搜索、切换聚合或单个平台、选分类与排序、切换网格或列表，并按链接打开。排行榜可切换五个平台、搜索榜名、在榜单内找歌或播放全部。
2. 「音乐 → 音乐库 → 添加服务器」支持 Navidrome 和 Subsonic。连接后可浏览歌曲、专辑、艺术家、服务器收藏和共享歌单。「最近添加歌曲」从服务器最新专辑中读取歌曲，并按入库时间排序，可继续加载更多专辑中的歌曲。「我的歌单」旁可创建服务器歌单；每行右侧「⋯」可编辑名称、简介和公开状态，或确认后删除歌单（保留歌曲文件）。长按歌单行可上下拖动，靠近页面边缘会自动滚动，松手保存当前服务器和账号在本机的顺序；取消拖动恢复原顺序。每个歌单详情的排序按钮旁有小刷新图标，刷新和排序图标均无外圈；点刷新会从服务器重新获取歌曲和歌单信息。资料库歌曲的「⋯ → 加入歌单」可选自己拥有的歌单，也可新建后直接加入。若服务器只提供歌曲的入库日期，歌单的排序菜单会显示「加入资料库日期」。
3. 听书内置[随身听书公开源合集 5.7](https://github.com/whykang/ssts--Android/releases/download/v5.7/Sources-v5.7.zip)，首次进入时从应用资源安装或升级旧官方包，保留源的编号、启用状态和设置；用户移除后不自动重装，使用自定义更新地址或较新版本的同名包不会被替换。「有声书 → 插件」仍可从文件或网址导入，也可手动导入／更新公开源合集。各源的登录和设置在插件菜单中。听书页、章节页和播放器不再提供本机下载或服务器下载入口。
4. 部署 [yinlangserver Docker 版](backend/yinlangserver/README.md) 后，在「总设置」填地址与令牌、启用推送并保存。下载时选择保存到手机或推送到服务器。
5. 在线音乐先按所选音质依次尝试支持的平台音源。所选档位全部失败后，播放才按音质逐级回退，并显示成功使用的档位。本机下载、手机推送和服务端单曲下载按选定档位执行。应用和下载服务优先根据媒体文件内容识别音频格式，避免把响应头误写为 MP3 的 FLAC 拒绝。资料库歌曲按源文件下载。

听书首页沿用音乐库的主卡与小卡布局：左侧为封面发现卡，右侧为书架、插件和听书设置，下方展示继续收听及收藏封面。发现页参考[随身听书的发现功能](https://github.com/whykang/ssts--Android#功能)，可在同一页切换来源、选择分类、切换封面网格／列表，滚动接近底部时加载下一页，也可手动加载或刷新。来源按插件提供的听书、评书、广播、播客等分组排列；菜单及分类地址完全使用插件的 `categoryMenus`／`categoryPage` 返回值，支持广播、央视直播及播客的非 HTTP 标识。列表按书籍地址去重，重复分页地址停止继续加载，失败可重试。当前浏览内容按源和插件版本缓存，返回详情后复用分类、内容与位置，切源或离页会取消当前请求；封面仅在可见时加载，并使用有声书缓存。

Navidrome 歌单中，有歌曲编辑权限的账号可在歌曲「⋯」菜单选择「移出歌单」，只移除当前这一项，保留歌曲文件。权限优先使用服务器返回的 `readonly` 状态；旧版服务器未返回该字段时，须明确匹配歌单所有者。提交前会重新查询权限并核对服务器原始歌曲顺序，避免排序显示、重复歌曲或列表变化导致移错；完成后刷新歌单。权限字段依据 [Navidrome 歌单接口](https://github.com/navidrome/navidrome/blob/master/server/subsonic/playlists.go)。

## 缓存与自动更新

- 「总设置 → 缓存管理」可分别设置音乐与有声书的缓存上限，默认各 512 MB，设为 0 可关闭。缓存优先复用，超限时清理最久未使用的数据。在线歌曲支持分段缓存，播放接近尾声时会补齐解码器跳过的分片。播放器直接走网络时，应用会另外读取同一音质的文件写入缓存，这种情况下会多用一次音频流量。看到「已可离线播放」后可断网重播，优先使用所选音质，也可使用其他已完整缓存的档位。HLS 按在线播放处理。手动下载的文件独立于缓存。
- 在线歌单、排行榜和详情优先显示上次加载的列表。列表缓存有效期为 3 小时，过期后在不计费网络后台更新，下次进入时显示更新结果。也可点「刷新列表」立即获取。榜单封面随卡片进入可见区域自动加载；列表未给封面时，只取榜首歌曲的缩略图，不再为找图加载完整榜单或尝试其他名次的封面。榜首无图、缩略图失败或平台没有单曲查询接口时保留默认背景，不回退下载原图。从榜单详情返回在线排行榜会复用本次浏览的列表、封面和滚动位置；手动点刷新可重新检查榜首封面。
- 「音乐设置 → 自动更新歌单」可选每次打开、每 3／6／12 小时、每天或关闭，默认仅在不计费网络更新。自动更新覆盖关注的在线歌单、默认聚合歌单和已连接的 Navidrome 歌单，手动检查还覆盖已浏览的在线歌单和各平台默认歌单页。安卓后台任务会在系统允许时运行。
- 「总设置 → 音源更新」显示待更新源，可手动检查，也可启用自动更新。通过网址导入的 JS 或 ZIP 会记住导入地址。通过文件导入的源可以补填更新直链。LX 源自己发布的更新通知也会显示。
- 播放在线歌曲时，底部状态条显示调用的 LX 音源以及解析结果。

## 播放器

- 底部播放条的播放／暂停按钮叠放在封面中央，点击切换后显示 2 秒再自动淡出；按钮隐藏后仍可点封面控制播放，点歌曲文字或长按封面展开播放器，右侧保留播放队列。封面由播放服务异步加载并复用缓存，同时以图片传给系统媒体会话和通知，供通知栏与锁屏显示；切歌时会清除上一首的封面并忽略过期请求。
- 点唱片、封面或「⋯」打开播放器菜单。可收藏、推送下载、选择播放模式和样式、切换在线音乐音质、调节均衡器和媒体音量。音质取决于 LX 音源，音效取决于设备和音频输出。
- 全屏播放器的「投送」可搜索同一局域网内的 AirPlay 音频设备，支持传统 AirPlay 音频与 AirPlay 2 实时音频。电视显示配对码时，在手机输入 4 位数字。投送期间可用播放器控制进度和接收设备的音量，停止投送会切回手机。接收端需要可通过 IPv4 访问。投送输出为 44.1 kHz、16 位立体声，手机本地音效只对本机播放生效。
- 左右滑动显示区或点「歌词」按钮，在唱片或封面与歌词之间切换。轻点歌词区收起上下控制栏，再点或按返回键恢复。竖滑浏览歌词，当前歌词随播放高亮。在线音乐和 Navidrome 的歌词取决于来源。
- 全屏播放器默认使用方形封面，并根据封面生成柔焦背景。可以从播放器菜单换成旋转黑胶。支持窗口模糊的 Android 12 或更新版本会在播放菜单、播放队列和音效弹窗后模糊背景。
- 「音效」提供十段均衡器、快速预设、自定义预设、环境混响与干湿调节、独立升降调和耳机立体声环绕。「恢复原声」暂时关闭音效并保留设置。均衡器频点和预设曲线参考 [lxserver 2.2.0](https://github.com/XCQ0607/lxserver/releases/tag/v2.2.0)，使用 Apache-2.0 许可。
- 进度条和播放控制固定在屏幕底部。用上一首、下一首按钮手动切歌。点击播放模式按钮依次切换顺序、列表循环、单曲循环和随机，长按可直接选择。
- 循环和倍速之间的太阳或月亮按钮单独切换播放器配色。进度条下方显示当前音频可读取的格式、码率和采样率。
- 歌曲行的「⋯」菜单可选择「下一首播放」或下载。播放页右侧的队列按钮可查看、切换和移除待播歌曲。点爱心后，可在「音乐 → 我喜欢的音乐」查看本机收藏。
- 睡眠定时可以选择分钟数或播完当前内容暂停。有声书按章节播放，支持前进 30 秒、后退 15 秒和按书保存倍速。

## Docker 下载服务

有现成的 `build/SoundShelf-Docker.zip` 时，解压后进入其中的 `backend` 目录。源码构建则先按后面的说明生成音乐目录包。

```sh
cp .env.example .env
# 先编辑 .env，再启动
docker compose up -d --build
```

| 配置项 | 用法 |
| --- | --- |
| `DOWNLOAD_TOKEN` | 设置至少 32 字符的随机令牌，用于安卓 App 和管理页。 |
| `BIND_ADDRESS` | 默认仅监听宿主机回环地址。直接从手机访问时填写服务器局域网地址。通过反代时按反代位置配置绑定。 |
| `DOWNLOAD_PORT` | 默认 8787。 |
| `MUSIC_DIR` / `AUDIOBOOK_DIR` | 两个宿主机成品目录。分别挂给你的音乐整理容器和有声书服务。目录需允许容器用户 UID 1000 写入。 |
| `PRIVATE_MEDIA_HOSTS` | 下载地址或自建解析接口位于局域网时，填写允许访问的准确主机名或 IP，用逗号分隔。 |
| `MAX_DOWNLOAD_BYTES` | 每个任务的下载大小上限，默认 2 GiB。 |

管理页位于服务地址根路径。填写令牌后可以搜索五个平台、通过音频地址手动添加音乐或有声书、管理音乐解析接口，并查看任务进度。手机推送已经解析的媒体地址和相关信息，服务器直接取文件。服务器搜索后的下载可调用配置的解析接口，它接受 JSON `{source, quality, musicInfo}`，应返回 `{url, headers?}`。

下载中的文件位于挂载目录下的隐藏子目录 `.soundshelf-work`。整理容器应忽略该子目录，读取下载完成后移出的音频。音乐尽可能写入标题、歌手和专辑标签。有声书按书名建目录，章节文件名保留顺序。HLS 有限点播由 Docker 中的 FFmpeg 合成 M4A。带字节区间、受保护加密或直播的 HLS 清单会报告失败。Android 本机下载支持音频直链，HLS 下载走服务器。

## 从源码构建

需要 Node.js 22 或更高版本、JDK 17、Gradle 8.13、Android SDK 36、NDK 27.2.12479018 和 CMake 3.22.1。首次构建会获取 Media3 和 AirPlay 发送库。生成目录包时需要 lxserver v2.2.0 的源码目录。

```powershell
New-Item -ItemType Directory -Force .reference | Out-Null
curl.exe -fL 'https://codeload.github.com/XCQ0607/lxserver/zip/refs/tags/v2.2.0' -o .reference/lxserver.zip
tar -xf .reference/lxserver.zip -C .reference lxserver-2.2.0/src/modules/utils/musicSdk lxserver-2.2.0/src/utils/lyricUtils lxserver-2.2.0/LICENSE
npm ci
npm run catalog
.\scripts\build-apk.ps1 -Sdk 'C:\path\to\AndroidSdk'
.\scripts\package-docker.ps1
```

已有上游源码时可通过 `LXSERVER_SOURCE` 指定目录。生成音乐目录包后，也可以用 Android Studio 打开工程或使用 Gradle 8.13 执行 `gradle :app:assembleDebug`。

## 上游与验收范围

- 音乐目录适配基于 [lxserver v2.2.0](https://github.com/XCQ0607/lxserver/releases/tag/v2.2.0)。生成包内有 Apache 2.0 原文、署名、修改说明和依赖许可证。上游 README 另列项目使用条款。
- AirPlay 音频发送使用 [airplay2-sender-cpp](https://github.com/akustikrausch/airplay2-sender-cpp/tree/fc913509039412790aa2427558d35178aa7842ea)。APK 内的 `assets/licenses/airplay` 包含许可证和第三方声明。Android 构建为 32 位接收缓冲区的位移运算补了位宽判断。
- 首页齿轮取自 [Flutter Cupertino Icons 的 gear_alt](https://api.flutter.dev/flutter/cupertino/CupertinoIcons/gear_alt-constant.html)，转换为 Android 矢量资源；MIT 许可证保存在 `assets/licenses/cupertino/LICENSE`。
- 听书运行环境按 [ssts--Android 的公开插件接口](https://github.com/whykang/ssts--Android/blob/main/docs/plugin-development.md) 实现，内置[官方公开源合集 5.7](https://github.com/whykang/ssts--Android/releases/download/v5.7/Sources-v5.7.zip)原始 ZIP，支持用户继续导入及管理插件。
- 目前为调试构建。五个平台的现网接口、38 个听书源的逐源播放及下载、Navidrome 实例和 Docker 实际运行均待联调。第三方源中的登录、验证和临时地址需要逐源验收。

- 0.6.9：投送入口增加 DLNA 音频接收设备发现、播放/暂停、切歌、进度和音量控制；在线地址及手机缓存通过局域网 HTTP 转发，音频格式须由接收端支持，暂不转码 HLS。手机与接收端需在可互访的同一局域网。
- 播放器底部六个无外圈按钮等宽排列：歌词、循环、明暗、定时、投送、队列。播放速度可从三点菜单调整，点击唱片不再打开菜单。在线歌单及榜单歌曲卡片统一为音乐库样式。

- 0.7.0：参考音流 2.0.1-beta.15 重建 Navidrome 分组登录表单（别名、主机、端口、路径、HTTPS、账号密码和连接地址预览）。总设置新增个性化与在线播放音质。
- 0.7.1：音乐库“发现”页移除首页和音乐库快捷卡片；移除个性化中的“发现页作为首页”；服务器任务支持清除已完成与失败的历史记录。
