# 音浪 YinLang

音浪是面向 Android、iPhone 和 iPad 的音乐与有声书播放器。一个应用里可以逛在线排行榜、播放自己在 Navidrome 上收藏的专辑，也可以在断网后继续听已缓存的歌曲和章节。

## 在线音乐

- 在网易云音乐、QQ 音乐、酷狗音乐、酷我音乐和咪咕音乐间搜索歌曲，按平台浏览排行榜。在线歌单可按分类或关键词查找，也能通过分享链接打开。榜单和歌单支持列表、卡片布局，列数可按屏幕宽度调整。
- 导入兼容的 LX 音源后，可选音质、收藏、加入队列或下载到本机。播放时可提前解析下一首，也可开启预缓存。已完整缓存的歌曲可以离线重播。实际可播放的曲目、音质和歌词由音源及平台提供。
- 连接兼容的下载服务后，可按可用音质把歌曲推送到服务器保存。搜索页提供本机搜索历史，便于重用常搜的歌名或艺人。

## Navidrome 个人曲库

- **发现和搜索**　浏览歌曲、专辑、艺人及收藏。发现页提供随心听、常听专辑、随机推荐和最近添加。可从歌曲详情进入对应的专辑或艺人页。
- **歌单管理**　查看自己的和其他用户共享的歌单，新建歌单或长按调整自己的歌单排列。拥有权限时可编辑名称、简介、公开状态和曲目，支持封面上传的服务器也可更换歌单封面。
- **专辑和批量选择**　按专辑原曲序将整张专辑保存到「专辑歌单」，也可从搜索结果多选歌曲或专辑，加入已有歌单或新建歌单。
- **离线访问**　服务器暂时断开时可查看已经缓存的歌单和曲目列表，继续播放已下载或完整缓存的音频。歌单可手动下拉更新。Wi‑Fi 和移动网络可各自选择原始音频或服务器提供的转码音质。

## 音质与格式

| 音频类型 | 支持的格式与播放方式 |
| --- | --- |
| 常用有损音频 | MP3、AAC／M4A。Ogg Vorbis 和 Opus 的兼容性取决于设备、系统和容器。 |
| 常用无损音频 | FLAC、ALAC／M4A、WAV／PCM、AIFF。实际可播放的位深、采样率和声道取决于设备与解码器。 |
| DSD | 从 Navidrome 获取 DSF 或 DFF 原文件，在设备上解码为 PCM 播放。播放器分别显示源 DSD 规格和 PCM 输出信息。 |

播放器在读取到数据时显示格式、码率和采样率。Android 提供十段均衡器、自定义预设和混响等音效。iPhone 和 iPad 接入兼容 USB DAC 后，可选跟随曲目向系统请求输出采样率。实际输出取决于系统和设备。

## 播放器、歌词与投送

- **封面和唱片**　切换专辑封面与旋转黑胶。播放器主题可单独调节明暗，iPad 横屏可将封面或唱片与歌词并排显示。
- **同步歌词**　有逐字时间的歌词会随播放进度逐渐点亮，普通 LRC 则逐行高亮。支持调节字号，Navidrome 曲库还可选择匹配在线歌词。
- **播放控制**　支持播放队列、随机与循环、睡眠定时，以及兼容曲目的交叉淡入淡出。可从锁屏控制播放，Android 使用系统媒体通知，iPhone 和 iPad 支持控制中心。
- **无线投送**　向兼容设备投送 AirPlay 或 DLNA 音频。通过 iPhone 或 iPad 屏幕镜像，还可在电视上显示封面、唱片和同步歌词。

## 有声书

导入兼容的听书插件后，可按书源、分类查找有声书、评书、广播和播客。将节目收藏到书架，按章节播放并接续上次进度，支持调节倍速和设置睡眠定时。支持下载的章节可保存到本机离线收听。
