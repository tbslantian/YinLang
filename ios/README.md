# 音浪 iOS / iPadOS

原生 SwiftUI 通用应用，最低 iOS / iPadOS 17。iPhone 与 iPad 使用同一套安卓页面结构，iPad 仅扩展可用宽度、封面网格列数并支持横竖屏，不增加侧栏。首页默认经典影像，直接复用安卓版 `home_music_light/dark`、`home_books_light/dark` 原图。

## 0.8.5 播放与布局修复

构建号 8：播放器参数行读取实际音轨的格式、码率和采样率；系统估算码率缺失时，PCM 使用音轨描述计算实际码率。解析过程使用安卓样式浮动通知，成功提示保留 2 秒。音源按需串行调用，验证通过立即返回，不启动后续音源；取消播放时终止验证请求。修复 UI 自动化的容器标识覆盖、部分可见按钮点击及尺寸比较容差，并修正测试账号准备与页面加载的时序。通过 GitHub Actions 进行设备编译及 iPhone / iPad 模拟器验证，实际结果以对应构建记录为准。

## 安卓界面风格同步

后续修改（尚未编译验证）：平板首页与发现音乐入口提高卡片高度及屏幕占比，保留两列和原有素材；播放器封面区/歌词区支持左右滑动并保留歌词纵向滚动。缓存命中增加文件检查，失效的本地音频直接走在线解析重试一次，保留原缓存及本机下载，不因读取失败自动删除或替换；写入新缓存前检查完整响应与音频可播放性，用户清理时取消未完成写入。

- 扩大平台按钮点击区域，限制封面绘制范围并禁止装饰层拦截触摸；切换平台时清空旧分类，取消旧请求并忽略过期结果。

- Navidrome 我的歌单支持点击文字及整行空白进入，右侧操作入口保留；拖动预览使用实际行宽和行高。
- 播放队列显示序号，左滑露出“移除”按钮；移除后重新编号，移除当前歌曲前面的条目仍保留当前播放，移除最后一项清空播放状态。

缓存播放、歌词滑动、平台点击、歌单整行点击和队列移除回归用例已补充，等待本轮构建运行。

本轮追加（尚未编译验证）：脚本初始化、解析调度和网络回调统一返回 `null` 给 WebKit，业务结果继续通过消息桥传回，避免 JavaScript 返回类型转换错误中断播放。新增有声书播放后切回在线音乐、Navidrome 的真实音频回归用例，以及异步调度返回 Promise 时的 WebKit 回归用例。播放器横屏自动显示左侧封面/旋转唱片、右侧歌词及下方控制，窄高空间压缩控件间距；竖屏保留上下布局。横屏提供封面/唱片切换，歌词仍可滚动、点击定位。旋转布局与唱片切换 UI 用例尚待运行。

音乐库追加（尚未编译验证）：左上角按安卓逻辑通过 `getScanStatus` 显示“服务器名称 · xxxx 首歌曲”，统计不可用时保留服务器名称。发现及右侧三个快捷卡片保持 1.3:1 比例铺满内容宽度，快捷卡片高度随宽度扩展为 72–104，发现卡片同步对齐三张快捷卡片总高度；去掉音乐库发现卡片上的箭头，听书入口保持原样。

在线歌单/排行榜追加（尚未编译验证）：两页均提供独立显示工具行，列表/卡片按钮点击区域扩大为 44×44，分类和排序移到独立一行。增加卡片列数选择，默认自动（手机 2 列、宽屏 iPad 4 列）；手机最多 2 列，iPad 最多 4 列，同时按当前窗口宽度保证卡片至少 140 点宽。列表模式禁用列数选择。两页分别记忆显示样式，手机/iPad 分别记忆列数，窗口收窄时临时减少实际列数。样式按钮边缘点击和列数设置回归用例待下次编译运行。

## 构建

GitHub Actions 的 **iOS universal unsigned build** 在 macOS 上生成设备 archive、未签名 IPA，并在 iPhone / iPad 模拟器上运行测试。构建产物 `YinLang-iOS-unsigned` 包含 IPA、SHA256 校验值、Xcode archive、测试结果和日志。未签名 IPA 需要自行签名后安装，无需将证书或 Apple ID 写入仓库。

macOS 本地构建：

```sh
# 在仓库根目录，先按根 README 准备 .reference/lxserver-2.2.0
npm ci
npm run catalog
node ios/scripts/prepare-resources.mjs
python3 ios/scripts/generate-project.py
xcodebuild -project ios/YinLang.xcodeproj -scheme YinLang \
  -configuration Release -destination 'generic/platform=iOS' \
  -archivePath ios/build/YinLang.xcarchive CODE_SIGNING_ALLOWED=NO archive
```

也可直接打开 `YinLang.xcodeproj`。源文件变动后重新运行项目生成脚本。生成的目录包、原图与官方听书源资源不重复提交；构建时从已有安卓/共享目录准备。

## 验收边界

iOS 使用系统 AirPlay。DLNA 转发支持当前在线文件和本机文件，HLS 不进行转码；自动发现需要签名时具有 Apple 的多播网络权限，未开通时可手动填写设备描述 XML 地址。`Multicast.entitlements` 提供相应配置参考，未签名构建不要求权限证书。音效通过本机音轨处理，HLS、受保护媒体和外部投送受系统输出路径限制。自动更新在进入前台时按周期执行，后台调度遵循 iOS 限制。音频格式取决于 iOS 解码能力。第三方音乐源、听书网站、登录验证码、Navidrome 实例及真实 AirPlay / DLNA 设备仍需使用实际账号与设备联调；模拟器编译和测试不能替代这些验收。
